# junction-releases
## Junction 0.9.21: achievements from GOG, Epic and EA

### Achievements from more launchers
- **Junction now shows your achievements from GOG, Epic Games and the EA app, not only from Steam:** on the game page, next to the game on Home, in Classic and in Stats.
- **GOG:** read from GOG Galaxy on your PC, so you don't need to sign in. You get names, pictures, how rare each one is, and when you unlocked it. They're as up to date as the last time Galaxy ran.
- **Epic Games:** shown when you're signed in to Epic in Junction (your picture → Accounts and keys). You get names, pictures, rarity and unlock dates.
- **EA app:** shown when you're signed in to EA in Junction. EA doesn't share pictures or rarity, so these achievements show a star instead.
- Achievements show for the games you've played.
- **If you have a game on more than one launcher** (or on several Steam accounts), the game page has a picker above the list. The copy you're furthest along in comes first.

### Changed
- **Preferences → Theme is now one row, like Layout and Style.** The choices open in a side menu next to it, so the menu is shorter.
